# 前端 UI 原型设计说明

项目方向：资源拓扑监控与运维控制台

本方案用于指导美术设计师绘制前端原型。重点描述页面结构、视觉层级、组件状态、交互反馈和响应式降级，不涉及后端实现、代码结构或接口契约。

## 1. 产品整体视觉方向

### 资源拓扑可视化

用接线图表达公网入口、服务引擎与内网目标之间的关系。

### 状态监控与告警

通过状态颜色、端口频谱和活动记录，让异常快速可见。

### 高效运维操作

通过命令面板和抽屉式表单快速进入操作流程。

### 推荐视觉基调

* 深色优先，适合运维控制台与大屏展示。

* 信息密度适中，突出状态、连接关系和异常。

* 使用卡片、网格、细线和少量高亮色。

* 图表必须有清晰的图例与文字说明。

* 所有监控组件都需要保留列表或文字信息作为降级视图。

* 端口区间用不同宽度的色块表达。

* 预留区域使用斜纹底色，与已占用区域区分。

### Kiosk 设计规范

* 无普通控制台顶栏导航。

* 无抽屉、命令面板和编辑按钮。

* 右上角显示当前时间和连接状态灯。

* 采用大字号、宽间距和高对比度。

* 告警区优先显示异常资源。

* 窄屏时允许网格重排，禁止内容横向溢出。

# 8. 活动记录 / 飞行记录仪

活动记录是中期功能，展示资源变化、操作历史、异常与补偿事件。可放置在总览右侧或 Kiosk 告警区域。

### 状态分级

* 信息：普通操作和状态变化。

* 警告：异常恢复、补偿、回滚等事件。

* 错误：资源故障或操作失败。
