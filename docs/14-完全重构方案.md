# 完全重构方案

## 重构范围与原则

- **原则**：Simple Made Easy，简单大于完美，人类可读
- **不动**：系统生命周期（system.clj）、认证体系（auth.clj）、业务领域（forward/caddy/docker）、测试框架
- **重点**：WebSocket → SSE、前端 JS 简化、服务端推送代码清理

---

## 一、WebSocket → SSE（核心改造）

### 删除
- `src/culvert/web/ws.clj` → 整体删除
- `core/ws-ticket-store`、`ws-ticket-generate`、`ws-ticket-consume` → 删除
- `core/cleanup-web-security-state!` 中的 ws-ticket 清理逻辑 → 删除
- `server.clj` 中 WebSocket Upgrade 分支（if websocket upgrade）→ 删除
- `handlers.clj` 中 `POST /ws/ticket` 端点 → 删除
- `system.clj` 中 `:stats-broadcaster` 对 ws 的引用 → 更新为 sse

### 新增
- `src/culvert/web/sse.clj`（替代 ws.clj）
  - `channels` atom：`#{channel}`（无需用户信息，认证已在连接时验证）
  - `sse-handler`：接受 GET /events，验证 SSE ticket，返回 chunked 响应
  - `broadcast!`：向所有 channel 发送 `data: {...}\n\n`
  - `broadcast-stats!`：推送容器/VM stats 事件（保留逻辑，只改传输层）
  - `start-stats-broadcaster!` / `stop-stats-broadcaster!`：直接复用 ws 中的线程模式

### SSE Ticket 策略
- 不使用一次性消费（EventSource 断线后会自动重连，需要重复使用同一 ticket）
- 页面渲染时生成 SSE ticket，嵌入 `<meta name="sse-ticket">`，TTL 60 分钟
- `/events` 端点：验证 ticket 是否在 store 中且未过期（不消费）
- `core.clj`：新增 `sse-ticket-store`、`sse-ticket-generate`、`sse-ticket-validate`
- `cleanup-web-security-state!`：清理过期 SSE ticket（同 CSRF 逻辑，过期即删）

### CSP 更新
- `connect-src 'self'`（移除 `ws: wss:`）

---

## 二、前端 JS 简化（main.js）

### 删除
- `wsReconnectDelay`、`wsMaxReconnectDelay` → 删除（EventSource 自带指数退避）
- `fetchWsTicket()`、`openWebSocket()`、`connectWebSocket()`、`scheduleWsReconnect()` → 全部删除
- `panelRefreshMap` 对象 → 保留（SSE 消息格式不变）

### 新增
- `connectSSE()`：读取 `<meta name="sse-ticket">` → `new EventSource("/events?ticket=xxx")`
- `EventSource.onmessage`：处理 `refresh` 和 `stats` 事件（逻辑与原 ws.onmessage 完全相同）
- `EventSource.onerror`：打印日志（断线重连由浏览器自动处理，无需手写）

---

## 三、服务端路由清理（server.clj / handlers.clj）

### server.clj
- 删除 WebSocket upgrade 分支（`if upgrade=websocket`）
- 添加 GET /events 路由（在 `route-dispatcher` 之前处理，需直接返回 async channel）
- raw-handler 回归到单纯的 `handlers/route-dispatcher`

### handlers.clj
- 删除 `handle-ws-ticket`（POST /ws/ticket 端点）
- 将所有 `ws/broadcast!` 替换为 `sse/broadcast!`
- 更新 require：sse 替代 ws

---

## 四、system.clj 更新

- `:stats-broadcaster` 的 start!/stop! 改为 `sse/start-stats-broadcaster!` / `sse/stop-stats-broadcaster!`
- require 更新：sse 替代 ws

---

## 五、views.clj 更新

- 页面渲染时调用 `core/sse-ticket-generate` 生成票据
- 嵌入 `[:meta {:name "sse-ticket" :content ticket}]`

---

## 执行顺序

1. 新建 `sse.clj`（参照 ws.clj，去掉 WebSocket 协议细节）
2. 修改 `core.clj`（添加 SSE ticket，删除 WS ticket）
3. 修改 `server.clj`（删除 WS upgrade，添加 /events 路由）
4. 修改 `handlers.clj`（替换 broadcast，删除 /ws/ticket）
5. 修改 `system.clj`（更新 require 和组件引用）
6. 修改 `views.clj`（嵌入 SSE ticket meta）
7. 修改 `main.js`（EventSource 替代 WebSocket）
8. 删除 `ws.clj`
9. 更新相关测试文件
10. 验证：`bb check`、`bb test`、`clojure -M:test`
