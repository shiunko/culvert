# 13-2 P2 命令面板

上级文档：[13 前端原型对齐与落地计划](13-前端原型对齐与落地计划.md)

## 目标

按原型的 ⌘K / Ctrl+K 命令面板，提供键盘驱动的高效运维入口；命令只做导航或打开已有表单，**不在面板内直接执行危险操作**。

## 交付物

| 类型 | 文件 |
|---|---|
| 视图 | `src/culvert/web/views.clj`（`#command-registry` + 覆盖层结构） |
| JS | `public/console.js`（命令面板行为；与 P1 同一文件） |
| CSS | `styles/app.css`（`pf-palette-*`） |
| 图标 | `src/culvert/web/ui/icon.clj`（复用） |

## 依赖

- P1 的令牌、图标库、`console.js`、契约表。

## 验收标准

- ⌘K / Ctrl+K 打开，输入实时筛选，↑↓ 与 Enter 可用，Esc 关闭且不误关 Drawer。
- 普通用户看不到管理类命令；无 SmolVM 能力时不出现创建虚拟机命令。
- 无 JS 时页面功能不受影响（命令面板整体不渲染行为，仅作为可选增强）。
- 键盘可达，焦点不逃逸，`aria-*` 正确。

## 风险与注意

- 命令清单必须由服务端按能力条件渲染，避免前端越权暴露入口；执行仍受后端授权约束。
- 面板内不做 mutation，全部转交已有 Drawer/表单，保持单一校验路径。
