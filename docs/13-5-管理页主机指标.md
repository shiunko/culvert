# 13-5 管理页主机指标

上级文档：[13 前端原型对齐与落地计划](13-前端原型对齐与落地计划.md)

## 目标

按原型的"管理"页视觉，为单机 culvert 提供**真实**的本机指标卡（CPU/内存/磁盘/端口池），并保留现有"用户与配额 / 主机容器分配"功能。**不照抄原型中虚构的集群节点。**

## 交付物

| 类型 | 文件 |
|---|---|
| 指标适配 | `src/culvert/observability/host.clj`（新增，纯解析 + 边界 I/O） |
| 路由 | `src/culvert/web/handlers.clj`（`GET /panel/host`） |
| 视图 | `src/culvert/web/views.clj`（`render-host-metrics` + 管理页重皮） |
| CSS | `styles/app.css`（`pf-host-*`，复用 `pf-kpi-card`） |

## 依赖

- P1 的令牌、图标库；现有 admin 二级导航（用户与配额 / 主机容器分配）。

## 验收标准

- 管理页显示真实本机 CPU/内存/磁盘/端口池，数据与系统实际一致（抽样核对）。
- 非 Linux 平台缺失指标显示 `—` 并说明，不报错、不造假。
- 保留用户配额与容器分配全部功能，仅视觉更新。
- 不出现 node-primary-01 之类的虚构集群节点。

## 风险与注意

- 主机指标是 I/O 与平台相关代码，务必把解析与读取分开，解析可测、读取失败可降级。
- 管理页原有 admin 授权边界不变；主机指标片段同样经 `wrap-auth` + `admin-only`。

## 实施记录（2026-09-14）

P5 已落地：

- 新增 `src/culvert/observability/host.clj`：纯解析 `parse-meminfo`/`parse-loadavg` 与边界 I/O 分离；CPU 负载优先读 `/proc/loadavg`，JVM 下回退反射 `OperatingSystemMXBean.getSystemLoadAverage`（Babashka 不含 `java.lang.management`，回退返回 nil）；内存解析 `/proc/meminfo`；磁盘用 `java.io.File` 的 `getTotalSpace`/`getUsableSpace`（取数据目录）；控制面运行时长取进程启动时刻；5 秒 TTL 缓存。
- `views.clj` 新增 `render-host-metrics-content` 与 `port-pool-usage`：CPU 负载/内存/磁盘/端口池各一条 `pf-meter`（≥80% 红、≥50% 黄），缺失项显示 `—` 并注明原因（如“非 Linux 平台暂不支持系统内存读取”）；页脚为真实“运行容器/微虚机”与“控制面运行时长”。
- 管理页顶部新增 `#host-metrics` 卡；其下保留原有「用户与配额 / 主机容器分配」两个子页，视觉沿用青蓝令牌。
- `handlers.clj` 新增 `GET /panel/host`（`wrap-auth` + `admin-only`，与 `/panel/users` 同边界）；`derived-panels` 追加 `host-metrics`，`public/main.js` 的 `panelRefreshMap` 同步，配 60 秒轮询。

### 与原始计划的偏差（如实记录）

1. **端口池聚合放在 `views.clj` 而非 `host.clj`**：端口占用要读 forward/caddy/docker/smolvm 的领域状态，若放进 `observability/host.clj` 会造成 observability→领域的反向依赖；因此 `host.clj` 只负责系统指标，端口池由本就读领域状态的 `views/port-pool-usage` 计算。
2. **`host-metrics` 不登记 OOB**：`fragment-registry` 中其 `:atoms` 为空集，仅靠 WS 广播（`derived-panels`）+ 60 秒轮询刷新，避免每次 mutation 的 OOB 里多出一段仅管理员可见、变化很慢的主机卡标记。
3. **CPU 负载跨运行时**：`/proc/loadavg` 在 JVM 与 Babashka 的 Linux 上都可读；mac 开发下 Babashka 返回 nil（显示 `—`），JVM 通过反射回退可读。

验证：`bb fmt-check`、`clj-kondo`（0/0）、`bb check`、`bb test`（167/898）、`clojure -M:test`（167/929）、`node --check` 通过；实测 `/panel/host` 普通用户 403、管理员 200 且含 `pf-host`/`端口池`/`磁盘`/`CPU 负载`/`控制面运行时长`；管理员 dashboard 含 `host-metrics`、普通用户不含。新增 `culvert.observability.host-test`（meminfo/loadavg 解析、缓存 TTL）与 `port-pool-usage-aggregates-real-ports`、`host-panel-is-admin-only`。
