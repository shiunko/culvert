# 13-1 P1 主题重置与总览可视化

上级文档：[13 前端原型对齐与落地计划](13-前端原型对齐与落地计划.md)

## 目标

把当前"紫粉渐变 + emoji + 无 reset"的界面重置为原型的"青蓝 cyber-ops"设计系统，并把总览从 4 张数字卡改成"欢迎横幅 + 配额环 + KPI + 接线图 + 端口频谱"，同时合并「转发」Tab、接通真实延迟探针。

## 风险与注意

- 协议同步点最多：任一 fragment id / WS 事件名 / colspan 漏改都会静默失效，按 `src/culvert/web/AGENTS.md` 修改守则逐条核对。
- 探针是新增系统组件，必须可开关、可失败隔离；不要让它影响主链路启动。
- 原型是 React 视觉稿，禁止把 Tailwind utility 直接写进 Hiccup；一律翻译为 `pf-` 组件类。

### 与原始计划的偏差（如实记录）

1. **运行时长对 forward/caddy 不可得**：领域状态里 forward/caddy 条目没有 `createdAt`（仅 docker/smolvm 有），因此「延迟 / 运行时长」列对 forward/caddy 只显示探针延迟，运行时长的第二行仅在有 `createdAt` 时出现。未为此给 `db.clj`/领域新增持久化字段（避免在 P1 触碰生产 JSON schema）。
2. **探针默认启用**：`config` 新增 `:probe-enabled?`（默认 true，`probeEnabled:false` 关闭）、`:probe-interval-ms`（默认 15000）、`:probe-timeout-ms`（默认 300）。只探测已配置的 forward/caddy 目标，不探测请求中的任意 host。
3. **OOB 策略由 `true` 改为 `innerHTML`**：原 `add-oob-attr` 用 `hx-swap-oob="true"`（outerHTML），会在第一次 OOB 后把片段容器的 `hx-get`/`hx-trigger` 一并替换掉，导致总览可视化面板的轮询失效（该问题此前已潜伏于 `overview-stats`）。改为 `innerHTML` 后容器属性保留，轮询与 WS 刷新可持续。
4. **i18n 去 emoji**：`src/culvert/i18n.clj` 中状态、按钮、配额、面板标题等可见 emoji 已批量移除或改为中文文本；服务器启动日志（`main.clj`）与领域日志中的 emoji 未动（非界面）。
5. **接线图/频谱对容器与微虚机目标不探测延迟**：探针只覆盖 forward/caddy 目标，故 docker/smolvm 行的延迟显示 `—`，状态仍取真实运行态。
