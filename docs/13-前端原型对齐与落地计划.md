## 2. 已确认决策

| 决策 | 结论 |
|---|---|
| 反向代理 Tab | **合并进「转发」Tab**：一级导航变为 总览 / 转发 / 容器 / 虚拟机 / 管理；转发 Tab 内用二级 Segmented 分「端口转发 / 域名反代」 |
| 缺失监控指标 | **新增真实 TCP 延迟探针**：列表与接线图显示真实可达性与延迟；吞吐不做，运行时长由 `createdAt` 实算 |

| 管理页 | **加真实单机 host 指标**（CPU/内存/磁盘/端口池），不虚构集群节点 |
| 原型幻想字段 | 吞吐、集群节点、连通性测试、视图模式切换器一律不照抄 |

### 3.2 排版

- **mono 优先**：端口、IP、ID、tab 标签用等宽字体 + `tabular-nums`；描述性文字用 sans。
- 圆角 8px（`rounded-lg`）/ 12px（`rounded-xl`）。
- 必须补全局 reset：`body { margin: 0 }`、`font-family` 栈、`box-sizing: border-box`、`button/input/select { font: inherit }`、统一 `:focus-visible`。

### 3.3 动效（原型 `globals.css`）

- `pf-flow-dash`：`stroke-dasharray: 6 4`，1.2s linear infinite，用于 alive 连接线。
- `pf-target-glow`：3s 定位高亮。
- `pf-striped-reserved`：45° 斜纹预留段。
- 细滚动条（6px）。
- 全部尊重 `prefers-reduced-motion: reduce`。

## 4. 技术栈映射原则

| 原型 | 本仓落地 |
|---|---|
| React 组件 / useState | Hiccup 纯函数 + 服务端 DTO；状态刷新走 HTMX |
| 客户端交互（悬停联动、定位高亮、面板、时钟） | `data-*` 属性 + 原生 JS，**不引 React/Node 依赖** |
| Tailwind utility 类 | 继续手写 `pf-` 组件类（`styles/app.css` 仍 `source(none)`，暂不启用 utility 扫描） |
| `lucide-react` 图标 | 新增 `src/culvert/web/ui/icon.clj` 内联 SVG 子集，替换全部 emoji；无构建依赖 |
| Next.js 路由 | 现有 `route-dispatcher` + `fragment-registry` |

## 5. 全局契约

### 5.1 新增路由（全部 `core/wrap-auth`）

```text
GET /panel/topology   → #topology-view
GET /panel/spectrum   → #port-spectrum
GET /panel/activity   → #activity-feed
GET /panel/host       → #host-metrics
GET /wall             → Kiosk 页面（render-wall）
GET /console.js       → 新静态文件
```

### 5.2 fragment-registry / panelRefreshMap 追加

| DOM id | 触发事件 | 端点 | 依赖 atoms |
|---|---|---|---|
| `topology-view` | `refresh-topology` | `/panel/topology` | forward/caddy/docker/smolvm |
| `port-spectrum` | `refresh-spectrum` | `/panel/spectrum` | forward/docker/smolvm |
| `activity-feed` | `refresh-activity` | `/panel/activity` | 四域 + activity |
| `host-metrics` | `refresh-host` | `/panel/host` | host + 四域 |

`handlers.clj` 新增 `broadcast-mutation!`，把派生视图统一追加进现有 27 处 `ws/broadcast!`，避免漏改导致静默失效。

### 5.3 DOM 数据属性

- `data-resource-key`：forward=`port_protocol_method`，caddy=`domain`，docker/smolvm=`id`。用于悬停联动与点击定位。
- `data-tab`：定位后跳转的一级 Tab。
- `data-subtab` / `data-tab-panel-sub`：二级导航（**必须作用域化**，见 13-1）。
- `data-command` / `data-command-label` / `data-command-keywords`：命令面板注册表。

### 5.4 静态资源四处同改

新增 JS 必须同时改：`route-dispatcher`、页面 `<script>`（`asset-url` 指纹）、`build.clj` 打包（`public/` 应自动覆盖，需确认）、CSP（`script-src 'self'` 已放行）。

## 7. 全局风险

1. **表头 / colspan / 骨架三处不同步** → 列表错列；列表列重构时必须同批改 `render-*-tbody`、`ui/skeleton` 的 colspan、`fragment-registry`。
2. **二级 Tab 作用域 bug**：`tabs.js` 的 `activateSubtab` 目前全局查询 `[data-tab-panel-sub]`，加第二组会与 admin 串；必须先抽作用域化共用函数。
3. **探针新增系统组件**：触及组合根并引入对外网络行为，必须 `:probe-enabled?` 开关 + 失败隔离 + 只探测已配置目标。
4. **host 指标跨平台**：生产 Linux 完整，mac 开发降级；解析函数必须独立单测。
5. **契约漂移**：路由、DOM id、WS 事件三处必须同批对齐，漏改表现为静默失效。
